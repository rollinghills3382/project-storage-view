Questions for you

  1. Main view: which of A, B or C should be the default? Shipping two behind a toggle is also an option.
  2. Grouping: these mockups gather everything an app owns into one block, even files outside Program Files (Docker's WSL disk, Adobe's media cache, Spotify downloads). Keep that, or show plain folders only?
  3. Free space: show it only in the bar at the top (as now), or also as a block inside the visualization?
  4. Actions: view-only, or should it offer Uninstall and Move to Recycle Bin from the detail panel?
  5. Platforms: Windows only for now, or macOS and Linux too? This decides the tech stack.
  6. Look: colors are grouped by category (Games, Development, and so on). Would you rather color by file type or by age?
